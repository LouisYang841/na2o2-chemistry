2. 为什么 Na₂O₂ 里的“O₂”不叫氧气？

这也是很多初学者容易掉进去的坑。我们对比一下这两个“O₂”：

这里的两个O原子，是被Na原子死死拉住的。它们是一个整体，不能随便跑出去，不具有氧气的性质。

真正的氧气分子 O₂ (自由的)

这是两个O原子手拉手组成的独立分子。这才是我们呼吸的“氧气”，它在常温下是气体，可以到处飞。

打个比方：就像“蛋黄”和“鸡蛋”。Na₂O₂里的O就像在鸡蛋壳里的蛋黄（被绑住了）；而O₂是打碎了壳，掉在碗里的蛋黄（独立出来的）。你不能指着壳里的蛋黄说“这是煎蛋”对吧？

4. 回到她的错题：计算过程怎么写？

题目已知：跑出来的 O₂ 气体质量是 0.32g。求：过氧化钠的质量分数（先求纯的过氧化钠质量）。

第一步：写下方程式，把已知和未知标在下面。

2Na₂O₂ + 2H₂O = 4NaOH + O₂↑

第二步：算相对分子质量。

Na的原子量是23，O的原子量是16。

1个 Na₂O₂ 的相对分子质量 = 23×2 + 16×2 = 46 + 32 = 78。

因为她前面有系数2，所以 2个 Na₂O₂ 的总质量是 78 × 2 = 156。

生成物 O₂ 的质量是：16 × 2 = 32。

第三步：列比例式（就像她卷子上写的，但要注意格式）。

设纯的过氧化钠质量为 x：

156 / x = 32 / 0.32g

交叉相乘：32x = 156 × 0.32

解得：x = 1.56g。

（计算过程在这里，孩子卷子上已经算出来了，做得很棒，但逻辑还要再顺一下）

第四步：求纯度（质量分数）。

纯的过氧化钠质量是 1.56g，样品总质量是 2g。

质量分数 = (纯物质质量 / 样品总质量) × 100%

= (1.56g / 2g) × 100% = 78%

所以，这个样品的纯度是 78%。
